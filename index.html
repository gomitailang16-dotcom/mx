読み込み・演算
この距離より遠くの地図は、取得も表示もしません（軽くなります）。右の数字欄なら、スライダーの最大(20km)を超えて入力できます。
小さいほど細かい（1が最大）。近づいたときの粗さ・ぼやけが気になるときは小さく。
進む先の壁を、どこまで先まで調べるか。長いほど先読みできますが、少し重くなります。

表示・操作
クリックで視点操作 / WASD 移動 / Space ジャンプ(長押しで上昇・素早く2回でスペクテーター。車ではジャンプ) / Shift 走る・ブースト / F 飛行・スペクテーター（Space↑ C/Q↓） / E インベントリ / 1〜9・ホイール スロット選択 / 右クリック or Z アイテムを使う / R 乗る・降りる / V 一人称・三人称 / O 設定 / H 画面表示の切替 / X 当たり判定 / B 車のブレーキ / [ ] 地図の高さ / Esc 視点解除
